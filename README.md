# EAZY

A modern, mobile-first ecommerce web app prototype for EAZY.

## EAZY v0.1

This first version is intentionally frontend-only. It uses demo product data so we can refine the customer experience before connecting Firebase/Firestore.

### Goals

- Modern ecommerce homepage
- Search and category discovery
- Flash deals
- Product cards
- Product detail experience
- Cart and wishlist interactions
- Mobile-first responsive layout
- Clean foundation for Firebase/Firestore

Firebase will be introduced after the interface and data model are established.
